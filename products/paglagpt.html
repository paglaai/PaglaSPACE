PRODUCT · MODEL ARCHITECT

PaglaGPT

The official AI Architect of the PaglaAI ecosystem. Local-first, design-first, and hybrid local+cloud. Built for Apple Silicon hardware constraints and the full Pagla stack.

View repository Read documentation

Architectural role & governance

Design-first sequencing

Enforces the design authority from PaglaDESIGN before any implementation begins, preventing UI drift and fragmented CSS.

Hardware realism

Enforces the 16 GB Apple Silicon memory ceiling, ensuring models and workloads run comfortably on consumer Apple Silicon hardware.

Ecosystem alignment

Stays synchronized with PaglaMLX, PaglaROUTER, PaglaSHELL, and the canonical registry in ecosystem.json.

Core capabilities

Technical peer review

Acts as an uncompromising architectural peer, scrutinizing data contracts, tool boundaries, and local runtime efficiency.

Multi-surface deployment

Operates both as a custom model assistant configuration and as a local-first interface connected via PaglaROUTER and PaglaMLX.

Zero telemetry posture

Promotes strict data sovereignty, deterministic prompt templates, and local execution kernels without cloud lock-in.

RAG & token grounding

Interacts with local MCP servers to query design tokens and architectural RFCs via pure lexical BM25 retrieval.
