PaglaDESIGN v1.3 — the agent manual finds its home

The operating manual that once lived beside the site has moved into the design authority. Relocated to .ai/agent-manual/, it is now written as procedure only: it inherits tokens, components, templates, and MCP tools from the authority instead of redefining them.

The version it replaced carried its own palette, its own fonts, its own invented components, and a fabricated lint CLI. None of that survives. The manual now documents the prompt formula, the lint severity model, the build playbook, and the anti-patterns — and the DOCX build script regenerates a canonical, monochrome-styled Word copy from the right paths.

The point of the move is durability. A manual that lives inside the authority cannot drift from it, because it no longer carries values of its own. It says how to use the system; the system says what the system is.
